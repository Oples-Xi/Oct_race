# Oct_race
## 简介
2027年第十届中国大学生工程实践与创新能力大赛,智能分拣赛项

1. ` laser.c/.h` 编写的驱动 MyAntenna L1-40激光测距模块，通过测量货物的位置来对传送带进行调速
2. `Motor.c/.h` 驱动Dji m2006马达的驱动
3. `Servo.c/.h` 驱动地盘舵机
4. `Control.c/.h` 状态机
5. `Kalman.c/.h` 滤波
6. `In.c/.h` 红外传感器
7. `Command.c/.h` 循环缓冲区
8. `tjc_usart_hmi.c/.h` [串口屏官方驱动库](http://wiki.tjc1688.com)

**每次添加新模块代码的时候请在readme里面描述该模块的介绍**
