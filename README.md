## 📖 项目简介

本项目是 2027 年第十届中国大学生工程实践与创新能力大赛**智能分拣赛项**的参赛项目，基于 **STM32F407ZGTx** 开发，用于实现传送带上货物的检测、定位与分拣控制。

- 使用 **MyAntenna L1-40 激光测距模块** 测量货物位置，对传送带进行调速
- 采用 **单马达三舵机** 架构：DJI M2006 马达驱动二级传送带，舵机实现分料、一级传送带和放行机构
- 通过 **卡尔曼滤波** 平滑距离数据，结合 **状态机** 管理完整控制流程
- 支持 **上位机联调** 与 **TJC 串口屏** 实时信息交互

## 🧰 硬件平台

| 部件 | 型号 / 说明 |
| --- | --- |
| 主控芯片 | STM32F407ZGT6 |
| 激光测距模块 | MyAntenna L1-40 |
| 马达 | DJI M2006（单马达驱动二级传送带） |
| 舵机 | 三舵机（底盘舵机 / 放行机构 / 一级传送带） |
| 红外传感器 | 货物在位检测 |
| 串口屏 | TJC 串口屏 |

## 📁 项目结构

```text
Oct_race/
├── Core/          # 主程序与各功能模块源码
├── Drivers/       # 底层驱动（HAL / CMSIS）
├── MDK-ARM/       # Keil 工程文件
├── screen/        # 串口屏相关资源
├── try.HMI        # 串口屏工程文件
└── Oct_race.ioc   # STM32CubeMX 配置文件
```

## 📦 模块结构

| 模块 | 说明 |
| --- | --- |
| `laser.c/.h` | MyAntenna L1-40 激光测距模块驱动，测量货物位置并对传送带调速 |
| `Motor.c/.h` | DJI M2006 马达驱动 |
| `Servo.c/.h` | 舵机驱动 |
| `Control.c/.h` | 状态机控制 |
| `Kalman.c/.h` | 卡尔曼滤波 |
| `In.c/.h` | 红外传感器驱动 |
| `Command.c/.h` | 循环缓冲区，接收上位机信息 |
| `tjc_usart_hmi.c/.h` | [TJC 串口屏官方驱动库](http://wiki.tjc1688.com) |
| `screen.c/.h` | 上位机与串口屏映射表 |
